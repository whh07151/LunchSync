▶ CU-06: 홈 대시보드  [막힘 - 안태환 작업 필요]
  막힌 이유:
    홈 화면에는 실시간 데이터가 표시되어야 합니다.
    (오늘의 세션 현황, 최근 주문, 추천 식당 등)
    이 데이터는 안태환이 만드는 백엔드 서버(NestJS)에서 옵니다.

    비유:
      화면(김지효) = 진열대
      데이터(안태환) = 진열할 상품
      → 진열대는 만들 수 있지만, 상품이 없으면 빈 진열대가 됨
      → 데모에서 빈 화면이 나오면 의미가 없으므로 대기 중

  필요한 것:
    - 안태환: NestJS 백엔드 API (세션/주문 데이터 조회 endpoint)
    - 또는: 팀 합의 후 Mock(가짜) 데이터로 UI만 먼저 완성

▶ CU-08: 친구/멤버 리스트  [막힘 - 우현호 작업 필요]
  막힌 이유:
    친구 목록을 가져오려면 카카오 친구 API가 연동되어야 합니다.
    카카오 로그인/초대 링크 연동은 우현호가 담당합니다.

    비유:
      친구 목록 화면(김지효) = 주소록 화면
      카카오 친구 API(우현호) = 주소록 데이터
      → 주소록 화면은 만들 수 있지만, 데이터 없이는 빈 목록만 나옴

  필요한 것:
    - 우현호: 카카오 로그인 + 친구 목록 API 연동 완료

──────────────────────────────────────────────────────────────────

▶ CU-16: 메뉴 목록/상세  [막힘 - 우현호 + 장다연 작업 필요]
  막힌 이유:
    메뉴 화면에는 실제 식당/메뉴 데이터가 필요합니다.
    식당 데이터 수집은 우현호, 데이터 정제/태깅은 장다연이 담당합니다.

    비유:
      메뉴 화면(김지효) = 메뉴판 디자인
      식당 데이터(우현호+장다연) = 메뉴판에 실을 내용
      → 메뉴판 디자인은 만들 수 있지만, 내용이 없으면 빈 메뉴판

  필요한 것:
    - 우현호: 식당 정보 API 연동 파이프라인
    - 장다연: 식당 데이터 정제 및 태깅

## 설명

[Nest](https://github.com/nestjs/nest) 프레임워크 TypeScript 시작 저장소입니다.

## 프로젝트 설정

```bash
$ npm install
```

## 프로젝트 컴파일과 실행

```bash
# 개발
$ npm run start

# 감시 모드
$ npm run start:dev

# 운영 모드
$ npm run start:prod
```

## 테스트 실행

```bash
# 단위 테스트
$ npm run test

# 종단 간 테스트
$ npm run test:e2e

# 테스트 범위
$ npm run test:cov
```

## 배포

NestJS 애플리케이션을 운영 환경에 배포할 준비가 됐다면 효율적으로 실행하기 위한 주요 단계를 따라야 합니다. 자세한 내용은 [배포 문서](https://docs.nestjs.com/deployment)를 참고하세요.

NestJS 애플리케이션을 배포할 클라우드 기반 플랫폼이 필요하다면 AWS용 NestJS 공식 배포 플랫폼 [Mau](https://mau.nestjs.com)를 참고하세요. 몇 가지 간단한 단계로 빠르고 쉽게 배포할 수 있습니다.

```bash
$ npm install -g @nestjs/mau
$ mau deploy
```

Mau를 사용하면 몇 번의 클릭만으로 애플리케이션을 배포해 인프라 관리보다 기능 개발에 집중할 수 있습니다.

## 참고 자료

NestJS 작업에 도움이 될 수 있는 자료입니다.

- 프레임워크를 자세히 알아보려면 [NestJS 문서](https://docs.nestjs.com)를 읽어 보세요.
- 질문과 지원은 [Discord 채널](https://discord.gg/G7Qnnhy)을 이용하세요.
- 더 깊이 배우고 실습하려면 공식 동영상 [강좌](https://courses.nestjs.com/)를 확인하세요.
- [NestJS Mau](https://mau.nestjs.com)를 사용해 몇 번의 클릭으로 AWS에 애플리케이션을 배포할 수 있습니다.
- [NestJS Devtools](https://devtools.nestjs.com)로 애플리케이션 그래프를 시각화하고 NestJS 애플리케이션과 실시간 상호작용할 수 있습니다.
- 프로젝트 지원이 필요하다면 공식 [엔터프라이즈 지원](https://enterprise.nestjs.com)을 확인하세요.
- 최신 소식을 받으려면 [X](https://x.com/nestframework)와 [LinkedIn](https://linkedin.com/company/nestjs)을 팔로우하세요.
- 구직하거나 채용 중이라면 공식 [채용 게시판](https://jobs.nestjs.com)을 확인하세요.

# Repository Ownership (Suggested for 4-person team)

## 1) Integration + Recommendation Lead
- Own `backend/api` integration contracts and recommendation stub evolution.
- Keep recommendation/vote/decision API consistency.

## 2) Data/RAG/Seed Owner
- Own `seed/` data conventions and sample scenario quality.
- Prepare later milestone data scaffolding for recommendation improvements.

## 3) Mobile/Design Owner
- Own app UX specs for `apps/customer-app` and UI flow docs.
- Track required backend contracts from user journey perspective.

## 4) Backend/Sync/POS Simulator Owner
- Own later milestone backend expansion for owner/POS sync.
- Prepare `apps/owner-app` and `apps/pos-web` integration plans.

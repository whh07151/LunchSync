# 웹 실행 오류 기록 (2026-06-02)

## 실행 명령

```bash
flutter run -d chrome --web-port 8080 \
  --dart-define=BACKEND_URL=http://13.125.165.80:3000/api
```

- Flutter 3.41.6(안정 버전, Dart 3.11.4)
- 백엔드: EC2 `http://13.125.165.80:3000/api`

## 요약

| 항목 | 결과 |
|------|------|
| 컴파일 / 빌드 | ✅ 성공 (오류 없음) |

주변 식당 크롤 API가 30초 타임아웃으로 반복 실패함.

## 1. (실제 오류) CrawlApiService 30초 TimeoutException — 반복 발생

### 로그
```
[CrawlApiService] crawlRestaurants 에러: TimeoutException after 0:00:30.000000: Future not completed
[CrawlApiService] crawlRestaurants 에러: TimeoutException after 0:00:30.000000: Future not completed
[CrawlApiService] crawlRestaurants 에러: TimeoutException after 0:00:30.000000: Future not completed
```

### 발생 흐름
- `lib/features/home/home_screen.dart:315` `_triggerCrawlIfCooled(pos)` 가
  GPS 위치 수신 시 호출
- → `lib/services/crawl_api_service.dart:59` `crawlRestaurants()`
  → `POST /api/crawl/restaurants` 호출, **30초 `.timeout()`** (crawl_api_service.dart:77)
- 백엔드 크롤(카카오 로컬 + 네이버 플레이스 + Gemini AI)이 30초를 초과해 응답 못 함 → `TimeoutException`

### 영향
- `crawlRestaurants()` 는 실패 시 `null` 반환하는 **fire-and-forget** 구조라
  앱 흐름/화면은 멈추지 않음 (크래시 아님).
- 단, 주변 식당 자동 채우기 기능이 동작하지 않음.

### 반복되는 이유 (주목할 점)
`home_screen.dart:336-337` 에서 결과가 `null` 이면 `_lastCrawlAt = null` 로 되돌림 →
쿨다운이 풀려 다음 GPS 스트림 이벤트에서 **즉시 재시도** → 30초 타임아웃이 계속 반복됨.
느린 크롤 엔드포인트를 30초 간격으로 계속 두드리는 모양새.

### 점검·개선 방향 (제안)
1. **백엔드 크롤 응답 속도** — `/api/crawl/restaurants` 가 30초 내 응답하는지 확인.
   네이버 상세/Gemini 병렬 호출이 병목으로 추정. (서버는 EC2에서 24/7 구동 중)
2. **타임아웃 실패 시 즉시 재시도 방지** — null(타임아웃) 시에도 일정 쿨다운을 유지하거나,
   타임아웃과 다른 실패를 구분해 백오프 적용.
3. 또는 크롤 트리거를 GPS 스트림이 아닌 명시적 사용자 액션/세션 생성 시점으로 제한.

## 결론
- **컴파일/실행 오류 없음.** 앱은 `http://localhost:8080` 에서 정상 서빙됨.
- 유일한 실질 오류는 **크롤 API 30초 타임아웃(반복)** 이며, 앱을 멈추진 않으나
  주변 식당 자동 채우기가 실패하고 느린 엔드포인트를 반복 호출함. 위 개선 방향 참고.

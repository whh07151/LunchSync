The Problem

매일 반복되는
"점심 뭐 먹지?" 의 피로

선택은 어렵고, 의견은 갈리고, 주문은 또 따로. LunchSync는 이 세 가지를 한 번에 풀어요.

😵‍💫

결정 피로

"아무거나"의 무한 루프. 누가 정해도 누군가는 아쉬운 점심.

🗣️

의견 취합의 번거로움

단톡방에서 메뉴 투표하고, 취합하고, 또 까먹고. 매번 수동.

🧾

흩어진 주문·정산

식당 정하면 주문은 또 따로. 더치페이 계산은 늘 머리 아픔.

Core Features

결정부터 픽업까지,
끊김 없는 한 흐름

팀 점심에 필요한 모든 단계를 하나의 앱에서. 재미있게 정하고, 빠르게 받아요.

01
🤖

AI 맞춤 추천

위치·예산·알레르기·최근 식사 이력까지 반영한 점수 기반 식당 추천.

02
🏆

이상형 월드컵

8강→4강→결승, 둘 중 하나 탭으로 즐겁게 메뉴·식당 결정.

03
🗳️

실시간 투표·룰렛

멤버 투표 집계, 룰렛·사다리로 즉석 결정도 가능.

04
💳

바로 주문·결제

결정된 식당 메뉴를 담아 토스페이먼츠로 결제까지 앱 안에서.

05
📍

실시간 픽업 추적

준비중→픽업가능→완료, 3초 폴링 + 예상 시간 + 사장님 음식 사진.

06
🧮

더치페이 자동계산

인원수로 1인당 금액 자동 계산, 카톡으로 바로 공유.

How it works

  3. 메뉴 담아 결제
  4. 픽업 상태 실시간 확인 + 별점

  3. 음식 사진·오늘의 한 줄 전송
  4. 매출·단골 통계 확인
